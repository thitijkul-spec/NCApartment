# สเปค Module: ใบเสร็จ/ใบกำกับภาษี (Receipt & Tax Invoice)

> **ออกแบบเองทั้งหมด ไม่ได้อิงภาพต้นแบบ** (ผู้ใช้แจ้งว่าไม่ซีเรียส แก้ทีหลังได้) — อิงจากมาตรฐานเอกสารการเงินทั่วไปของไทย + ข้อตกลงที่คุยไว้แล้วตอนทำสเปค `module_bill_key_features.md`

Sub-module ของหมวด "การเงิน" — ต่อยอดจาก [module_bill_key_features.md](module_bill_key_features.md) (data model `Payment` เดิมมี field เกี่ยวกับใบเสร็จ/ภาษีอยู่แล้ว)

สถานะ: ✅ สเปคเสร็จ (draft ออกแบบเอง — รอ confirm/แก้ไขทีหลังได้ตามต้องการ ก่อน implement)

---

## 1. หน้าที่ของโมดูล

จัดการเอกสารการเงินที่ออกให้ผู้เช่าเมื่อมีการชำระเงินจริง — พิมพ์/ดาวน์โหลดใบเสร็จรับเงินและใบกำกับภาษี, ค้นหา/ย้อนดูเอกสารที่เคยออก, ลบ/ยกเลิกเอกสารพร้อมผลต่อยอดบิล

ข้อมูลต้นทางมาจาก `Payment` ของ module บิลรายเดือนทั้งหมด — โมดูลนี้**ไม่มี data model ของตัวเองแยกต่างหาก** เป็นแค่ "มุมมอง + เอกสารพิมพ์" ของ Payment ที่มีอยู่แล้ว

## 2. Data Model (ส่วนเพิ่มเติมจาก `Payment` เดิม)

```
Payment (เพิ่มเติมจากที่นิยามไว้ใน module_bill_key_features.md)
- receipt_no             → string, nullable — เลขที่ใบเสร็จ, prefix "RCP-" (เช่น RCP-2026-08-0001) รันแยกตามอาคาร
- tax_invoice_no         → string, nullable — เลขที่ใบกำกับภาษี, prefix "TAX-" (เช่น TAX-2026-08-0001) รันแยกตามอาคาร
                            (คนละ sequence กับ receipt_no แม้จะออกพร้อมกันในการชำระครั้งเดียว — เผื่อบางครั้งออกใบเสร็จอย่างเดียวไม่มีภาษี)
- payee_name_snapshot     → string — ชื่อผู้รับเงิน/สาขา ณ เวลาที่ออกเอกสาร (ดึงจาก "ตั้งค่าหอพัก" ตอนนั้น)
- payee_address_snapshot  → string, nullable
- payee_tax_id_snapshot   → string, nullable — เลขผู้เสียภาษีของกิจการ (ใช้ในใบกำกับภาษีเท่านั้น)
```

**เหตุผลที่ snapshot ข้อมูลผู้รับเงิน:** เหมือนหลักการเดียวกับสัญญา — ถ้าที่อยู่/ชื่อสาขาเปลี่ยนในอนาคต เอกสารเก่าที่พิมพ์ไปแล้วต้องคงข้อมูล ณ วันที่ออกจริง ไม่เปลี่ยนตามค่าปัจจุบัน

## 3. หน้าจอย่อย

### 3.1 หน้ารายการ "ใบเสร็จ" (เมนูย่อยในหมวดการเงิน — ตามที่ตกลงไว้)
- Top bar: หัวข้อ "ใบเสร็จ" + subtitle "ค้นหา/ย้อนดูใบเสร็จและใบกำกับภาษีที่ออกไปแล้ว"
- Filter (ครบทุกแบบตามที่ตกลงไว้):
  - ช่วงวันที่ (`paid_at`)
  - ห้อง / ผู้เช่า (ค้นหาด้วยชื่อหรือเลขห้อง)
  - เลขที่เอกสาร (ค้นหาตรงกับ `receipt_no` หรือ `tax_invoice_no`)
  - ประเภทเอกสาร: ทั้งหมด / ใบเสร็จอย่างเดียว / มีใบกำกับภาษีด้วย
- ตาราง: เลขที่ใบเสร็จ, เลขที่ใบกำกับภาษี (ถ้ามี), ห้อง, ผู้เช่า, ยอดเงิน, วิธีชำระ, วันที่ออก, ปุ่ม "พิมพ์ซ้ำ" (dropdown เลือกพิมพ์ใบเสร็จ A5 / ใบกำกับภาษี A4 ถ้ามีทั้งคู่), ปุ่ม "ลบ"
- **ปุ่ม "ลบ" = ยกเลิกการชำระเงิน (Payment) ทั้งรายการ** (ไม่ใช่แค่ลบเอกสาร) ตามที่ตกลงไว้ในสเปคบิล — มี confirm dialog เตือนว่ายอดค้างของบิลจะเพิ่มกลับคืน

### 3.2 จุดที่ออกเอกสาร (เชื่อมจาก module บิลรายเดือน)
ทุกครั้งที่บันทึกการชำระเงิน (ไม่ว่าจากแอดมินกดเอง หรือยืนยันสลิปจาก LINE) — popup เล็กถามก่อนปิดหน้าต่างบันทึกเงิน:
1. ออก**ใบเสร็จ**เสมอ (บังคับ ไม่มี option ปิด) → gen `receipt_no`
2. Toggle "ออกใบกำกับภาษีด้วย" (ปิดเป็น default) — เปิดแล้วต้องกรอก ชื่อผู้เสียภาษี / เลขผู้เสียภาษี 13 หลัก (validate รูปแบบ) / ที่อยู่ตามใบกำกับภาษี ก่อนกดยืนยัน → gen `tax_invoice_no` เพิ่ม

### 3.3 หน้าตาเอกสารที่พิมพ์ออกมา

**ใบเสร็จรับเงิน — ขนาด A5, เรียบง่าย**
```
[ชื่อกิจการ/สาขา — payee_name_snapshot]
[ที่อยู่ — payee_address_snapshot]

              ใบเสร็จรับเงิน (RECEIPT)
เลขที่: RCP-2026-08-0001            วันที่: 14/08/2569

ได้รับเงินจาก: [ชื่อผู้เช่า]   ห้อง: [เลขห้อง]
รายการ: อ้างอิงบิลเลขที่ [bill_no] — [billing_month]
        (ถ้าจ่ายบางส่วน ระบุ "ชำระบางส่วน X/Y บาท")

ยอดเงิน: ฿[amount]   (ตัวอักษร: [จำนวนเงินเป็นตัวหนังสือไทย])
วิธีชำระ: [เงินสด / โอนเข้าบัญชี xxx]

ผู้รับเงิน: ....................................
```

**ใบกำกับภาษี — ขนาด A4, Formal เต็มรูปแบบ**
```
[โลโก้]  [ชื่อกิจการเต็ม — payee_name_snapshot]
         [ที่อยู่ — payee_address_snapshot]
         เลขประจำตัวผู้เสียภาษี: [payee_tax_id_snapshot]

                    ใบกำกับภาษี / ใบเสร็จรับเงิน
เลขที่: TAX-2026-08-0001                      วันที่: 14/08/2569

ผู้ซื้อ: [taxpayer_name]
เลขประจำตัวผู้เสียภาษี: [taxpayer_tax_id]
ที่อยู่: [taxpayer_address]

┌─────┬──────────────────────────┬───────────┐
│ ลำดับ │ รายการ                    │ จำนวนเงิน │
├─────┼──────────────────────────┼───────────┤
│  1  │ ค่าเช่าห้อง [เลขห้อง] เดือน [MM/YYYY] │  X,XXX.XX │
└─────┴──────────────────────────┴───────────┘
                                    รวมเงิน:  X,XXX.XX
                            (ยกเว้นภาษีมูลค่าเพิ่ม — ค่าเช่าที่พักอาศัย)
                                  ยอดรวมสุทธิ: X,XXX.XX

ผู้รับเงิน: ....................................        ตราประทับ (ถ้ามี)
```
> **หมายเหตุ VAT:** ค่าเช่าที่พักอาศัยได้รับยกเว้นภาษีมูลค่าเพิ่มตามกฎหมายไทย จึงออกแบบเริ่มต้นเป็น "ไม่มี VAT" (ยอดในใบกำกับภาษี = ยอดเดียวกับใบเสร็จ) — ถ้าในอนาคตต้องคิด VAT (เช่น มีค่าบริการอื่นที่ต้องเสียภาษี) ค่อยเพิ่ม toggle "จด VAT" ในหน้าตั้งค่าทีหลัง ยังไม่ทำตอนนี้

### 3.4 ข้อมูลกิจการที่ใช้พิมพ์เอกสาร
ดึงจาก module "ตั้งค่า" (ยังไม่ทำ) — ต้องมี field ขั้นต่ำต่อไปนี้ในหน้าตั้งค่าสาขา เพื่อให้โมดูลนี้ทำงานได้: ชื่อกิจการ/สาขา, ที่อยู่, เลขประจำตัวผู้เสียภาษี (ถ้ามี), โลโก้ (ถ้ามี) — **บันทึกไว้เป็นข้อมูลที่ module ตั้งค่าต้องรองรับ ไม่ใช่สร้างในโมดูลนี้**

## 4. Action/ฟังก์ชันสรุป

| Action | รายละเอียด |
|---|---|
| ออกใบเสร็จ | เกิดอัตโนมัติทุกครั้งที่บันทึกการชำระเงินสำเร็จ (บังคับ) |
| ออกใบกำกับภาษี | toggle เลือกเพิ่มตอนบันทึกการชำระแต่ละครั้ง ต้องกรอกข้อมูลผู้เสียภาษี |
| ค้นหา/กรองเอกสาร | ตามช่วงวันที่, ห้อง/ผู้เช่า, เลขที่เอกสาร, ประเภท |
| พิมพ์ซ้ำ | เลือกพิมพ์ใบเสร็จ (A5) หรือใบกำกับภาษี (A4) แยกกัน |
| ลบเอกสาร | ยกเลิก Payment ทั้งรายการ, ยอดค้างบิลเพิ่มกลับคืน, ต้อง confirm |

## 5. ความสัมพันธ์กับโมดูลอื่น

- **บิลรายเดือน**: ข้อมูลทั้งหมดมาจาก `Payment` ที่สร้างในโมดูลนั้น โมดูลนี้เป็นแค่หน้าจอ/เอกสารเพิ่มเติม ไม่มี table ใหม่
- **ตั้งค่า (ยังไม่ทำ)**: ต้องมี field ข้อมูลกิจการ (ชื่อ/ที่อยู่/เลขผู้เสียภาษี/โลโก้) ให้โมดูลนี้ดึงมา snapshot ตอนออกเอกสาร

## 6. Out of scope (MVP)

- การคิด VAT ในใบกำกับภาษี (ยกเว้นตามกฎหมายค่าเช่าที่พักอาศัย)
- e-Tax Invoice / ส่งเอกสารอิเล็กทรอนิกส์เข้าระบบสรรพากรอัตโนมัติ
- เลขที่เอกสารรูปแบบอื่นนอกจาก running number ต่ออาคาร (เช่น เชื่อมเลขใบกำกับภาษีจริงจากระบบบัญชีภายนอก)
