# สเปค Module: พัสดุ (Parcel)

อ้างอิงข้อมูลจาก [module_tenant_key_features.md](module_tenant_key_features.md) (LINE ID ผู้เช่า — ใช้ส่งแจ้งเตือน)

## 1. หน้าที่ของโมดูล

จัดการพัสดุที่มาส่งถึงอพาร์ตเมนต์ — บันทึกพัสดุเข้า, แจ้งเตือนผู้เช่าผ่าน LINE, ติดตามสถานะจนกว่าจะมีคนมารับ, เก็บประวัติพัสดุตกค้าง

**ขอบเขต multi-building:** ทุกอย่างในหน้านี้กรองตาม `building_id` ที่กำลังเลือกอยู่

## 2. Data Model

```
Parcel
- id
- building_id            → FK Building
- tenant_id              → FK Tenant, nullable — "โยงกับผู้เช่า" ไม่บังคับ ปล่อยว่างได้ถ้าชื่อผู้รับไม่ตรงกับผู้เช่าคนไหนในระบบ
- room_id                → FK Room, nullable — auto-fill ตาม tenant_id ที่เลือก (ไม่มีถ้าไม่ได้โยงผู้เช่า)
- recipient_name         → string, บังคับ (กรอกเอง ไม่มี OCR ในสโคปนี้)
- delivery_company       → string, nullable — เลือกจาก chip (Kerry, Flash Express, J&T Express, ไปรษณีย์ไทย, DHL, Ninja Van, Lalamove, SCG Express, พัสดุด่วน) หรือพิมพ์เอง
- tracking_no            → string, nullable
- photo_url              → string, nullable — รูปใบนำส่ง (ไม่บังคับ ข้ามได้ถ้าไม่มีกล้อง/เน็ตขัดข้อง)
- received_at            → datetime, บังคับ — วันที่และเวลาที่มาส่ง
- status                 → enum: arrived(พัสดุเข้า) | notified(แจ้งลูกบ้านแล้ว) | picked_up(รับพัสดุแล้ว)
- notified_at            → datetime, nullable — เวลาที่กดแจ้งเตือนล่าสุด (แจ้งซ้ำได้ อัปเดตทับ)
- picked_up_at           → datetime, nullable
- notes                  → text, nullable
- created_at / updated_at

Setting (ระดับอาคาร)
- parcel_overdue_days    → int — จำนวนวันก่อนตีตรา "ตกค้าง" (ตั้งค่าในหน้าตั้งค่า)
```

**สถานะ "ตกค้าง" เป็น flag คำนวณสด ไม่ใช่ physical state:**
`วันนี้ - received_at > parcel_overdue_days` และ `status != picked_up` → แสดง badge "ตกค้าง" ซ้อนกับสถานะหลัก (เหมือนแนวทาง `overdue` ใน `module_bill`)

## 3. หน้าจอย่อย

### 3.1 หน้ารายการหลัก "พัสดุ"
- Header: "พัสดุ" + subtitle "จัดการพัสดุที่มาส่ง" + ปุ่ม "+ บันทึกพัสดุ"
- Stat cards: ทั้งหมด / พัสดุเข้า / แจ้งแล้ว / ตกค้าง
- ช่องค้นหา: ค้นจากเลขห้อง / ชื่อผู้เช่า / ชื่อผู้รับ
- Filter tabs: ทั้งหมด / พัสดุเข้า / แจ้งลูกบ้านแล้ว / รับพัสดุแล้ว / ตกค้าง
- การ์ดรายการพัสดุแต่ละใบ: ชื่อผู้รับ, ผู้เช่า+ห้องที่โยง (ถ้ามี), สถานะ (badge), วันที่มาส่ง, ไอคอน action:
  - 🖼️ ดูรูปใบนำส่ง
  - ✏️ แก้ไขข้อมูล (แก้ชื่อผู้รับ/โยงผู้เช่า/บริษัทขนส่ง/เลขพัสดุ ฯลฯ)
  - 🔔 แจ้งเตือนผู้เช่าผ่าน LINE (กดเอง ไม่ auto — ดูหัวข้อ 4) กดซ้ำได้ = แจ้งเตือนซ้ำ
  - 💬 เพิ่ม/แก้ไขหมายเหตุ
  - ✓ เปลี่ยนสถานะไปขั้นถัดไป (arrived→notified→picked_up)
  - 🗑️ ลบพัสดุ — **hard delete ลบจริงทันที ไม่เก็บประวัติ** (มี confirm dialog ก่อนลบ)

### 3.2 Modal "บันทึกพัสดุที่มาส่ง"
ตามภาพที่แนบ (ตัด "ประเภทพัสดุ" และปุ่ม "สแกน AI อ่านชื่อผู้รับ" ออกจากสโคปนี้):
- ขั้นตอนที่ 1: ถ่ายรูป/อัปโหลดรูปใบนำส่ง (ไม่บังคับ — ข้ามได้ถ้าไม่มีกล้อง/เน็ตขัดข้อง)
- ชื่อผู้รับ* (กรอกเองทั้งหมด)
- โยงกับผู้เช่า (autocomplete ค้นหาจากรายชื่อผู้เช่าในอาคาร, ไม่บังคับ)
- วันที่และเวลาที่มาส่ง*
- บริษัทขนส่ง (chip เลือกด่วน + ช่องพิมพ์เอง)
- เลขพัสดุ
- หมายเหตุ

## 4. การแจ้งเตือนผู้เช่าผ่าน LINE

- กดปุ่ม 🔔 ที่การ์ดพัสดุ → ระบบส่งข้อความแจ้งเตือนไปยัง LINE ของผู้เช่าที่ผูกไว้ (`tenant_id` ต้องมีค่า และผู้เช่าต้องผูก LINE ไว้แล้วตาม `module_tenant`)
- ข้อความเป็น **fixed template auto-generate** จากข้อมูลพัสดุ (เช่น "มีพัสดุมาส่งที่ห้อง [เลขห้อง] จาก [บริษัทขนส่ง]") — ไม่มีการแก้ไขข้อความเองก่อนส่ง
- ถ้าพัสดุนี้ยังไม่ได้โยงผู้เช่า → ปุ่ม 🔔 กดไม่ได้ (disable) ต้องกดแก้ไขเพื่อโยงผู้เช่าก่อน
- กดครั้งแรก: เปลี่ยนสถานะ `arrived` → `notified` พร้อมบันทึก `notified_at`
- กดซ้ำ (สถานะเป็น `notified` หรือ `picked_up` อยู่แล้ว): ส่งข้อความซ้ำเฉยๆ ไม่เปลี่ยนสถานะ

## 5. การเปลี่ยนสถานะ

- **ไปข้างหน้า:** กดไอคอน ✓ ที่การ์ด → เลื่อนสถานะไปขั้นถัดไปตามลำดับ `arrived → notified → picked_up` (ถ้าเลื่อนจาก arrived ตรงไป picked_up ก็ยังไม่ผ่าน notified ได้ ไม่บังคับต้องแจ้งเตือนก่อนรับ)
- **ย้อนกลับ:** เลือกสถานะจาก dropdown/badge ได้อิสระ (เช่น กดรับพัสดุผิด ต้องกลับเป็น "แจ้งลูกบ้านแล้ว") — **มีกล่องยืนยันก่อนเปลี่ยนสถานะย้อนกลับทุกครั้ง**
- เปลี่ยนสถานะเป็น `picked_up` → บันทึก `picked_up_at`; ย้อนกลับออกจาก `picked_up` → เคลียร์ `picked_up_at`

## 6. ความสัมพันธ์กับ module อื่น

- **ผู้เช่า (`module_tenant`):** ใช้ LINE ID ที่ผูกไว้แล้วเพื่อส่งแจ้งเตือนพัสดุ; autocomplete ค้นหาผู้เช่าตอนบันทึก/แก้ไขพัสดุ
- **ห้องพัก:** `room_id` เป็นค่าที่ derive มาจาก tenant ที่เลือก ไม่ได้เลือกห้องตรงๆ ในฟอร์ม
- **ตั้งค่า:** กำหนดจำนวนวัน `parcel_overdue_days` สำหรับตีตรา "ตกค้าง"
