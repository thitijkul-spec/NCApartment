# ระบบจัดการหอพัก (Prototype)

## วิธีเปิดใช้งานครั้งแรก

1. ติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน LTS (ถ้ายังไม่ได้ลง)
2. เปิดโฟลเดอร์นี้ด้วย Terminal / PowerShell แล้วรันตามลำดับ:

```bash
npm install
npx prisma migrate dev --name init
npm run dev
```

3. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## วิธีเปิดใช้งานครั้งต่อไป

```bash
npm run dev
```

แล้วเปิด `http://localhost:3000`

## ข้อมูลถูกเก็บที่ไหน

ข้อมูลทั้งหมดบันทึกลงไฟล์ `prisma/dev.db` (ฐานข้อมูล SQLite) อยู่ในเครื่องนี้ ไม่หายเมื่อปิดเว็บ/ปิดเครื่อง

## สถานะฟีเจอร์

ใช้งานได้จริงแล้ว: ห้องพัก, ลูกค้า/Blacklist, การจองรายวัน, สัญญารายเดือน, บิล/ใบเสร็จ/รับชำระเงิน,
มิเตอร์น้ำ-ไฟ (จดรวมทีเดียว → ออกบิลอัตโนมัติ), แจ้งซ่อม (สร้างรายจ่ายอัตโนมัติเมื่อปิดงาน), แม่บ้าน (พิมพ์รายการ checkout),
Cross Check รายวัน, รายงาน (ค้างชำระ/ห้องว่าง/รายได้), แดชบอร์ดเจ้าของ, รายจ่าย/กำไรขาดทุน (บัญชีเงินสดอย่างง่าย),
ผู้ใช้งาน+สิทธิ์ (ล็อกอิน, เจ้าของ 1 คน, พนักงานหลายคนพร้อมกำหนดสิทธิ์รายโมดูล)

ยังไม่ได้ทำ (ต้องมีบัญชี/API ภายนอกก่อน):
- **LINE OA** (แจ้งเตือนลูกค้า, เซ็นสัญญาผ่าน LIFF, แจ้งซ่อมผ่าน LINE) — ต้องมีบัญชี LINE Developers (Messaging API + LIFF) ก่อน
- **อ่านสลิปโอนเงินอัตโนมัติ (OCR)** — ต้องเลือกผู้ให้บริการ OCR และมี API key
- **รับเงินผ่าน 2C2P** — เป็นแผน Phase 2 ตาม spec เดิม

เมื่อพร้อมสมัครบัญชีเหล่านี้แล้ว แจ้งได้เลย จะเชื่อมต่อให้ครบ
